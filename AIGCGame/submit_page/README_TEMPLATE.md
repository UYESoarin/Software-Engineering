# 一箭又一箭

> 基于 Python + Pygame 开发的四向箭头点击解谜小游戏。
> 本项目用于软件工程课程第二次个人作业，并使用 AIGC / Coding Agent 辅助完成需求分析、程序开发、测试与优化。

## 1. 项目简介

玩家观察棋盘中箭头的方向与阻挡关系，选择合适的顺序点击箭头：

- 前方没有其他箭头 → 箭头沿自身方向飞出棋盘并消失
- 前方存在箭头 → 本次操作失败，消耗一次失误次数，并播放碰撞反馈
- 清空全部箭头 → 当前关卡通关
- 失误次数归零 → 当前关卡失败，可重新开始

当前版本采用矩形网格、单格箭头、上下左右四个方向和直线射线检测。

## 5. 实现思路

### 5.1 分层

项目采用“状态机 + 规则 / 表现分离”的结构：

```text
main.py
   ↓
scenes.py
   ├── view.py
   ├── anim.py
   └── rules.py
          ↑
      levels.json
```

规则层负责盘面、方向、射线和资源变化；表现层负责窗口、输入、绘制和动画。

### 5.2 路径检测

方向增量：

```python
DIRS = {
    "up": (-1, 0),
    "down": (1, 0),
    "left": (0, -1),
    "right": (0, 1),
}
```

从箭头相邻格开始逐格检查，直到：

```text
发现其他箭头 → 阻挡
走出棋盘     → 可以飞出
```

边界判断应先于网格访问，避免 Python 负索引导致边缘状态错误。
