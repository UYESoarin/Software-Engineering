# 三、项目介绍

## 3.1 游戏目标

玩家需要观察箭头方向和相互阻挡关系，通过合理顺序点击箭头，使全部箭头飞出棋盘。

## 3.2 基础规则

| 状态 | 行为 |
|---|---|
| 前方无箭头 | 箭头飞出并消失 |
| 前方有箭头 | 箭头不能消失，消耗一次失误次数 |
| 全部箭头清空 | 当前关卡通过 |
| 失误次数归零 | 当前关卡失败 |
| 点击重开 | 恢复进入当前关卡时的初始状态 |

## 3.3 操作

```text
鼠标左键：点击箭头 / 按钮
重开：恢复当前关卡
```

## 4.3 路径检测

定义四方向增量：

```python
DIRS = {
    "up": (-1, 0),
    "down": (1, 0),
    "left": (0, -1),
    "right": (0, 1),
}
```

程序从当前箭头相邻格开始逐格扫描：

```text
当前箭头
   ↓
相邻格
   ↓
检查是否存在箭头
   ↓
继续前进
   ↓
走出棋盘
```

需要特别注意：

> 必须先判断坐标仍在棋盘范围内，再读取该位置是否有箭头。
