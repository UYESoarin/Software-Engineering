# 三、项目介绍

## 3.1 游戏目标

玩家需要观察箭头方向和相互阻挡关系，通过合理顺序点击箭头，使全部箭头飞出棋盘。

## 3.2 基础规则

| 状态 | 行为 |
|---|---|
| 前方无箭头 | 箭头飞出并消失 |
| 前方有箭头 | 箭头不能消失，消耗一次失误次数，播放碰撞反馈 |
| 全部箭头清空 | 当前关卡通过 |
| 失误次数归零 | 当前关卡失败 |
| 点击重开 | 恢复进入当前关卡时的初始状态 |

## 3.3 操作

```text
鼠标左键        ：点击箭头 / 按钮
「撤销」按钮     ：回退最近一次结算（无历史时禁用）
「重开」按钮     ：恢复本关开局快照
鼠标滚轮        ：以鼠标位置为中心缩放棋盘
鼠标中键拖拽    ：平移棋盘
Home 键         ：缩放归位到适合窗口
标题「选关」     ：进入关卡选择界面
标题「继续游戏」 ：恢复上次未完成的关卡
```

# 四、实现思路

## 4.1 项目架构

项目采用：

> 状态机 + 规则 / 表现分离

核心模块：

```text
main.py                      入口 + 主循环
    ↓
scenes.py                    场景状态机（标题/选关/对局/结果）
 ┌──┴─────────┐
view.py     anim.py          表现层：绘制 / 摄像机 / 动画
    ↑
rules.py  solver.py  score.py  save.py   规则层（不 import pygame）
    ↑
levels.json                   关卡数据（数据 / 规则分离）
```

说明：规则层负责盘面、射线、余次、快照、撤销、评分、求解与存档，全部为纯逻辑；表现层只把规则层结果画出来并处理输入。关卡坐标只进 `levels.json`，改关不改判定。

## 4.2 箭头表示

单支箭头使用：

```text
id  row  col  dir
```

例如：

```json
{
  "id": "a",
  "row": 1,
  "col": 0,
  "dir": "right"
}
```

## 4.3 路径检测（关键代码）

定义四方向增量：

```python
DIRS = {
    "up": (-1, 0),
    "down": (1, 0),
    "left": (0, -1),
    "right": (0, 1),
}
```

从箭头相邻格开始逐格扫描，核心代码如下（`rules.py`）：

```python
def _ray(self, row, col):
    idx = self.arrow_at(row, col)
    if idx is None:
        return None
    arrow = self.arrows[idx]
    dr, dc = DIRS[arrow["dir"]]
    r, c = row + dr, col + dc
    # 关键：先判断格子在不在盘内，再读占用。
    # 否则 Python 负索引会绕到网格另一头，边缘朝外箭会判错。
    while 0 <= r < self.rows and 0 <= c < self.cols:
        j = self._blocked_by(r, c, idx)
        if j is not None:
            return False, j      # 先碰到箭 → 阻挡
        r += dr
        c += dc
    return True, None            # 一路空到边界 → 可飞
```

# 八、扩展功能

## 8.1 扩展一：撤销一步

问题：误点被挡的箭会扣失误次数，降低容错体验。

设计：`Session` 内维护快照栈，每次结算前 `_snapshot()` 保存盘面与余次；`undo()` 弹栈恢复。

实现：`rules.py` 增加历史栈（上限 20），`scenes.py` 增加「撤销」按钮（无历史时禁用）。计时不回退，避免刷时间。

测试：T07/T08 通过。

## 8.2 扩展二：得分 / 计时 / 星级

最终规则：

```text
总分 = 700 × 准确度 + 300 × 时间分   （0–1000）
准确度 = 1 − 失误次数 / 初始余次
时间分 = 用时 ≤ par_time 记满分，超时最多再给 2×par_time 的线性衰减
星级  = 得分 ≥ 900 三星，≥ 700 两星，否则一星
```

实现：`game/score.py` 纯逻辑；`PlayScene` 累计 `elapsed`（撤销不回退）；结果画面显示星级/得分/用时/失误。

## 8.3 扩展三：保存进度

保存内容：`unlocked_level`、`in_progress`（关卡/箭头/余次/用时）、`best`（每关最佳分）。

保存时机：每次结算后自动保存；通关时解锁下一关并记最佳；失败清进行中。

加载时机：标题「继续游戏」读取 `in_progress` 恢复盘面、余次与用时。

异常存档处理：版本不符或 JSON 损坏时回退默认值，不影响启动。

## 8.4 扩展四：AI 自动求解

核心思想：把「谁必须先被清除」建模为 blocker → blocked 依赖图；删除箭头只会减少阻挡，故「不断选当前可飞箭」等价于 Kahn 拓扑排序，无需 DFS。

求解代码（`solver.py`）：

```python
def solve(level):
    arrows, adj, indeg = build_dependency_graph(level)   # j 挡 i → 边 j→i
    q = deque(i for i, d in enumerate(indeg) if d == 0)   # 入度 0 = 当前可飞
    order = []
    while q:
        i = q.popleft()
        order.append(i)
        for j in adj[i]:
            indeg[j] -= 1
            if indeg[j] == 0:
                q.append(j)
    return None if len(order) != len(arrows) else [arrows[i]["id"] for i in order]
```

测试：T09 八关均返回完整解序，T10 solution 与运行规则一致。

## 8.5 扩展五：视口拖动 / 缩放

边界：最小缩放 0.45、最大 2.0；大盘（9×10）自动缩小至完整显示。

## 8.6 扩展六：电子游戏风 UI

## 8.7 扩展七：碰撞动画

目标动画：

```text

```

最终参数：

```text

返回时长：0.25–0.58s（ease-in-out）
总时长：约 0.58s
```
